# Codex Pet Playground（ローカル読み込み版）

Codex Pet のスプライトシート（`pet.json` + `spritesheet.webp`）を、端末から読み込んで
ブラウザ内だけで再生・確認できる静的Webアプリ。

## 🔒 外部送信は一切発生しません

- 読み込んだ `pet.json` と `spritesheet.webp` は **サーバーへアップロードされません**。
- `fetch` / `XMLHttpRequest` / フォーム送信を一切使用していません。処理はすべて
  `FileReader` と `URL.createObjectURL` によるブラウザ内メモリ上の変換・描画のみです。
- 外部CDN・Webフォント・アナリティクス等の読み込みもありません。`index.html` 1ファイルに
  HTML/CSS/JavaScriptが完結しています。
- ページ上部にも同内容のバッジを常時表示しています。ブラウザの開発者ツールの
  Networkタブを開いた状態でファイルを読み込めば、通信が発生しないことを確認できます。
- ページを閉じる・再読み込みすると、読み込んだ内容はすべて破棄されます（保存機能なし）。

## 使い方

1. `index.html` をブラウザで開く（ローカルの `file://` でも、簡易HTTPサーバー経由でも可）。
2. `pet.json` と `spritesheet.webp` をドロップ、またはタップ/クリックしてまとめて選択する。
3. 画像サイズから v1 / v2 を自動判定し、情報パネル・アニメーション再生・16方向確認UIが有効になる。

### ローカルでの起動例

ビルド工程は不要。任意の静的サーバーで配信すればよい。

```bash
git clone https://github.com/kazukibass/codex-pet-playground
cd codex-pet-playground
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

`file://index.html` を直接開いても動作するが、ブラウザによっては `file://` 経由の
`<input type="file">` に一部制限がある場合があるため、動作確認は簡易HTTPサーバー経由を推奨する。

## 対応スプライト規格

| 規格 | 画像サイズ | グリッド | 用途 |
| --- | --- | --- | --- |
| v1 | 1536×1872 | 8列×9行 | 標準9動作。モバイル互換優先 |
| v2 | 1536×2288 | 8列×11行 | 標準9動作＋16方向の視線・向き |

セルサイズは共通で 192×208px。画像サイズがどちらにも一致しない場合は、
高さをセル高さ（208px）で割った行数で推定表示し、警告を表示する。

標準9行の割り当て：

| 行 | 状態 |
| ---: | --- |
| 0 | idle |
| 1 | running-right |
| 2 | running-left |
| 3 | waving |
| 4 | jumping |
| 5 | failed |
| 6 | waiting |
| 7 | running / active work |
| 8 | review |

v2のみ、行9・行10に8コマずつ、合計16方向を格納（未使用セルは透過想定）。
**方位の並び順（N始点・時計回り、行9→行10）はこのプレイグラウンド側の仮定であり、
Codex Pets本体の正式な並び順が別にある場合は一致しない可能性がある。** 16方向確認UIは
実際のアセットを目視で確認する用途に使う。

## 機能

- pet.json / spritesheet.webp の端末読み込み（アップロードなし）
- v1 / v2 の自動判定（画像サイズから判定、不一致時は推定＋警告）
- 9種類のアニメーションをボタンで切り替え
- 再生速度の調整（0.25x〜3.0x）
- 背景色の変更（透過チェッカー／プリセット／カスタムカラー）
- 表示サイズの調整（1x〜8x）
- v2のみ：16方向の視線をコンパスUIから個別に確認（静止フレーム表示）
- モバイル互換トグル：v2画像でも標準9行（v1相当）だけで再生し、16方向データを無視する。
  画面幅が768px未満の環境では初期状態でON。手動でいつでも切り替え可能。
- レスポンシブ対応（PC・モバイル両対応、ボタンはタップしやすいサイズ）

## 実装しなかったもの（今回のスコープ外）

- `.codex-pet.zip` の読み込み（旧構想）。今回は `pet.json` と `spritesheet.webp` を
  個別に読み込む方式に統一した。ZIP対応が必要になった場合は、ZIP展開ライブラリを
  同梱するか、ブラウザ標準の展開手段で追加実装する。
- タップ・スワイプによるジェスチャー操作（旧構想）。今回はボタン操作のみ。
- PWA化（ホーム画面追加・オフラインキャッシュ）、常駐表示（PiP・ウィジェット・
  フローティング表示等）。

## 公開について

このリポジトリはビルド工程なしの静的ファイル（`index.html` 1枚）のみで構成されている。
GitHub Pages（Settings → Pages → Source: Deploy from a branch → `main` / `(root)`）や
Cloudflare Pages等、任意の静的ホスティングにこのリポジトリをそのまま配置すれば公開できる。
公開後も外部送信を行わない構成に変更はない。
